Guide de Démarrage Rapide Novelist

Bienvenue sur Novelist, l'application ultime pour planifier, écrire et organiser vos histoires. Ce guide vous expliquera les bases pour démarrer sereinement.

1. Bibliothèque : Votre Collection de Projets

À l'ouverture, vous trouverez votre Bibliothèque : le centre de tous vos univers d'écriture.

  • Créer un projet : Appuyez sur “+”. Choisissez le modèle Roman standard ou un modèle basé sur un projet existant. Le projet est le conteneur principal de votre univers.
  • Modifier, définir la couverture ou supprimer : Appuyez sur les trois points.
  • Projets illimités : Vous pouvez créer autant de projets que vous le souhaitez !
  • Indicateurs de sécurité : Vert signifie sécurisé, rouge signifie qu'il faut sauvegarder pour éviter les pertes.

Appuyez sur un projet pour accéder à son espace de travail principal.

2. L'Espace Projet : Éléments Partagés

Dans un projet, vous bâtissez les fondations de votre univers. Les sections Intrigue (Plot) et Écrire (Write) servent de ressources partagées pour tous les livres du projet.

2.1 Intrigue : Planifiez les Fondations de votre Univers

Créez et gérez ici les éléments de votre monde : Thèmes, Personnages, Événements, etc.

  • Ajouter des éléments : Appuyez sur “+” pour créer un élément avec un titre (requis) et, optionnellement, un synopsis.
  • Personnaliser les catégories : Créez ou éditez des catégories selon votre style (ex: “Factions” ou “Planètes”).
  • Organiser les éléments : Utilisez le cercle d'état pour le suivi. Maintenez enfoncé pour supprimer ou réorganiser.
  • Vue détaillée : Modifiez les détails, relations, images et descriptions.

2.2 Écrire : Rédigez vos Scènes

Les scènes sont l'épine dorsale de votre écriture. Rédigez-les ici dans un espace partagé, prêtes à être utilisées dans n'importe quel livre du projet.

  • Créer des scènes : Appuyez sur “+” pour ajouter une scène avec un titre.
  • Éditeur de texte enrichi : Rédigez votre histoire et mentionnez des éléments d'Intrigue avec “@”.
  • Gérer les scènes : Attachez des éléments, divisez ou réorganisez les scènes.
👉 Important : Les scènes sont rédigées ici, mais n'apparaîtront pas dans le manuscrit final tant qu'elles ne sont pas attachées à un Livre spécifique.

3. Livres : Structurez vos Manuscrits

Un projet peut contenir un ou plusieurs Livres. Ils partagent la même Intrigue et les mêmes Scènes—parfait pour une série ou un spin-off !

3.1 Organiser : Structurez votre Livre

Dans un Livre, la section Organiser vous aide à façonner votre manuscrit en actes, parties et chapitres.

  • Ajouter des sections : Créez une arborescence pour diviser votre livre.
  • Attacher des scènes : Choisissez les scènes de la section Écrire partagée qui appartiennent à ce livre.
  • Réorganiser les sections : Réorganisez facilement les chapitres.
👉 Important : Seules les scènes attachées à la section Organiser d'un livre sont incluses dans le manuscrit final.

4. Planifier : Fixez des Objectifs

Restez motivé avec des objectifs clairs et suivez vos progrès.

  • Fixer des objectifs : Choisissez une cible de mots, une date limite, ou les deux.
  • Progrès quotidiens : Consultez votre graphique de mots chaque jour.

5. Prévisualiser et Exporter votre Livre

Quand votre livre est prêt :

  • Prévisualiser : Appuyez sur l'icône œil pour voir votre manuscrit.
  • Exporter : Appuyez sur Exporter et partager pour créer votre fichier en EPUB, ODT ou HTML.

6. Sauvegarde et Sync : Protégez votre Travail

  • Sauvegardes : Enregistrez vos données localement ou sur le cloud (Google Drive, iCloud).
  • Sync manuelle : Utilisez Envoyer vers le cloud et Recevoir du cloud.
👉 Important : Faites des sauvegardes fréquentes pour éviter de perdre votre travail.

7. Conseils pour les Nouveaux Utilisateurs

  • Commencez petit : Créez un seul projet avec un livre pour vous familiariser.
  • Profitez de l'univers partagé : Créez les profils de personnages dans Intrigue avant d'écrire vos Scènes.
  • Sauvegardez souvent : Ne risquez pas de perdre votre dur labeur.

Vous êtes prêt à démarrer votre aventure d'écriture avec Novelist ! Bonne écriture ! ✍️
