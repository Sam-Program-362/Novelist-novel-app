Novelist 快速入门指南

欢迎使用 Novelist，这是用于计划、编写和组织您的故事的终极应用程序。

1. 书库：您的项目集合

打开应用程序时，您会发现书库——管理所有写作宇宙的中心枢纽。

  • 创建项目： 点击 “+” 按钮。项目充当您故事宇宙的主容器。
  • 编辑、设置封面或删除项目： 点击三点菜单。
  • 无限项目： 您可以创建任意数量的项目！
  • 安全指示器： 绿色指示器表示安全，红色指示器表示需要备份以免丢失数据。

点击一个项目进入其主工作区。

2. 项目工作区：共享元素

情节 (Plot) 和 写作 (Write) 部分将作为此项目内所有书籍的共享资源池。

2.1 情节：计划您宇宙的构建块

在这里创建和管理核心元素：主题、角色、事件等。

  • 添加项目： 点击 “+” 创建新项目。每个项目都需要一个标题。
  • 自定义类别： 创建或编辑类别（例如“派系”或“星球”）。
  • 组织项目： 使用状态圆圈跟踪进度。长按可删除或合并。
  • 详细视图： 点击项目以编辑详细信息和富文本描述。

2.2 写作：起草您的场景

场景是您写作的支柱。您可以在共享池中起草它们，供项目中的任何书籍使用。

  • 创建场景： 点击 “+” 按钮添加带有标题的新场景。
  • 富文本编辑器： 编写故事并使用“@”提及情节元素。
  • 管理场景： 附加情节项目，拆分场景或重新排序。
👉 重要提示： 场景在这里起草，但在您将其附加到特定书籍之前，它们不会出现在最终稿中。

3. 书籍：构建您的手稿

一个项目可以包含多本书籍。它们共享相同的情节和场景——非常适合写系列小说！

3.1 组织：构建您的书籍

在组织部分，您可以将书籍分为幕、部分和章节。

  • 添加部分： 创建树状结构来划分章节。
  • 附加场景： 从共享池中选择属于本书的场景。
  • 重新排序： 轻松调整章节顺序。
👉 重要提示： 只有附加到书籍组织部分的场景才会包含在最终手稿中。

4. 计划：设定目标并跟踪进度

用明确的目标保持动力。

  • 设定目标： 选择字数目标、截止日期或两者兼而有之。
  • 每日进度： 查看您的字数图表。

5. 预览和导出书籍

当书籍结构完成后：

  • 预览： 点击眼睛图标查看您的手稿。
  • 导出： 点击导出和共享创建 EPUB、ODT 或 HTML 格式文件。

6. 备份与同步：保护您的工作

  • 备份： 将数据保存在本地或云端（Google Drive / iCloud）。
  • 手动同步： 使用发送到云端和从云端接收。
👉 重要提示： 经常备份以避免因设备问题而丢失工作。

7. 给新用户的提示

  • 从小处着手： 先创建一个项目和一本书来熟悉工作流程。
  • 拥抱共享宇宙： 在写场景之前，在情节中创建角色资料。
  • 经常备份： 不要冒险丢失您的辛勤工作。

您现在准备好与 Novelist 一起开启您的写作冒险了！祝您写作愉快！ ✍️
