Novelist クイックスタートガイド

物語の計画、執筆、整理のための究極のアプリ、Novelist へようこそ。

1. ライブラリ：プロジェクトのコレクション

アプリを開くと、すべての執筆ユニバースを管理する中心的なハブであるライブラリが表示されます。

  • プロジェクトを作成： 「+」 ボタンをタップします。プロジェクトはストーリーのユニバースのマスターコンテナとして機能します。
  • 編集、表紙設定、削除： 3点メニューを押します。
  • 無制限のプロジェクト： プロジェクトはいくつでも作成できます！
  • 安全インジケーター： 緑色のインジケーターは安全を意味し、赤色はバックアップが必要であることを示します。

プロジェクトをタップして、メインワークスペースにアクセスします。

2. プロジェクトワークスペース：共有要素

プロット (Plot) と執筆 (Write) セクションは、このプロジェクト内で作成するすべての本のリソースプールとして機能します。

2.1 プロット：ユニバースの要素を計画する

ここで世界の主要な要素（テーマ、キャラクター、イベントなど）を作成および管理します。

  • アイテムを追加： 「+」 ボタンをタップします。各アイテムにはタイトルが必要です。
  • カテゴリをカスタマイズ： スタイルに合わせてカテゴリを作成または編集します（例：「派閥」「惑星」）。
  • アイテムを整理： ステータスサークルを使用して進行状況を追跡します。
  • 詳細ビュー： アイテムをタップして、詳細やリッチテキストの説明を編集します。

2.2 執筆：シーンをドラフトする

シーンは執筆のバックボーンです。プロジェクト内のどの本でも使用できるように、共有プールにドラフトします。

  • シーンを作成： 「+」 をタップして、タイトルを持つ新しいシーンを追加します。
  • リッチテキストエディター： 物語を書き、「@」記号を使用してプロットアイテムに言及します。
  • シーンを管理： プロットアイテムを添付したり、シーンを分割したり、並べ替えたりします。
👉 重要： シーンはここでドラフトされますが、特定の本に添付されるまで最終原稿には表示されません。

3. 本：原稿を構成する

1つのプロジェクトに複数の本を含めることができます。それらは同じプロットアイテムとシーンを共有します—シリーズを書くのに最適です！

3.1 整理：本を構成する

整理セクションでは、本を幕、部、章に分割して構成します。

  • セクションを追加： 章に分割するためのツリー構造を作成します。
  • シーンを添付： 共有プールからこの本に属するシーンを選択します。
  • セクションを並べ替える： 章を簡単に並べ替えます。
👉 重要： 本の整理セクションに添付されたシーンのみが最終原稿に含まれます。

4. スケジュール：目標と進捗

明確な目標でモチベーションを維持しましょう。

  • 目標を設定： 文字数の目標、期限、またはその両方を選択します。
  • 毎日の進捗： 毎日の文字数のグラフを確認します。

5. 本のプレビューとエクスポート

本の構成が完了したら：

  • プレビュー： 目のアイコンをタップして原稿を確認します。
  • エクスポート： エクスポートして共有をタップして、EPUB、ODT、HTMLを作成します。

6. バックアップと同期

  • バックアップ： ローカルまたはクラウド（Google Drive、iCloud）にデータを保存します。
  • 手動同期： クラウドへ送信およびクラウドから受信を使用します。
👉 重要： デバイスの問題で作業を失わないように、頻繁にバックアップを取ってください。

7. 新規ユーザー向けのヒント

  • 小さく始める： ワークフローに慣れるために、1つのプロジェクトと1つの本を作成します。
  • 共有ユニバースを活用： シーンを書く前に、プロットでキャラクタープロフィールを作成しましょう。
  • 頻繁にバックアップ： 苦労して作成した作品を失わないようにしてください。

これで Novelist での執筆の冒険を始める準備が整いました！ハッピーライティング！ ✍️
